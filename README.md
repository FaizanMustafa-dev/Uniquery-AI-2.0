# 🎓 UniQuery AI 2.0 — Intelligent Academic Assistant

### An AI-Powered Learning Companion Built with Python & Streamlit

UniQuery AI 2.0 is a multi-functional academic chatbot designed to simplify studying, improve knowledge retention, and support independent learning.

Built using **Python and Streamlit**, the application combines three intelligent learning tools within a clean, interactive interface: **Query Bot, Study Buddy, and Quiz Master**.

The platform enables students to explore academic topics, generate structured study notes, and assess their understanding through interactive multiple-choice quizzes.

## 🚀 Key Features

### 🤖 1. Query Bot — Academic Question Answering
- Ask questions related to academic subjects and concepts.
- Receive AI-generated explanations and responses.
- Explore challenging topics through conversational interactions.
- Support self-paced learning and knowledge exploration.

### 📚 2. Study Buddy — Smart Notes Generator
- Generate organized study notes on selected topics.
- Present learning material in a question-and-answer format.
- Simplify complex academic concepts for easier understanding.
- Assist students with revision and exam preparation.

### 🧠 3. Quiz Master — Interactive MCQ Generator
- Generate multiple-choice questions based on study topics.
- Practice knowledge through interactive quizzes.
- Submit answers and receive instant results.
- Evaluate understanding and identify areas for improvement.

## 🏗️ Application Architecture

UniQuery AI 2.0 uses a modular approach that organizes its functionality into three learning modes.

**User Interface — Streamlit**

↓

**Select Learning Mode**

- Query Bot → Academic Question Answering
- Study Buddy → Q&A-Based Notes Generation
- Quiz Master → MCQ Generation and Evaluation

↓

**Python Application Logic**

↓

**Generated Academic Content / Quiz Results**

This approach provides a unified interface while keeping each learning tool focused on a specific educational task.

## 📦 Installation & Setup

### Prerequisites

- Python 3.x
- pip package manager
- Required project dependencies

### 1. Clone the Repository

```bash
git clone <your-repository-url>
cd Uniquery-AI-2.0
```

### 2. Install Dependencies

If the repository includes a `requirements.txt` file:

```bash
pip install -r requirements.txt
```

### 3. Run the Application

Launch the Streamlit application using its actual entry-point filename:

```bash
streamlit run <your-main-python-file>.py
```

Streamlit will provide a local URL for accessing the application through a browser.

*Note: Replace the placeholders with the actual repository URL and application entry point. Additional setup may be required depending on the AI services used.*
